## Project Description

This project is a simple console-based Recommendation System built using Python. It uses a Content-Based Filtering approach to suggest items (movies, books, or products) based on user preferences.

The system does not use any machine learning libraries and is implemented using only Python standard libraries. It demonstrates fundamental concepts of recommendation systems and basic artificial intelligence logic.

## Content-Based Filtering Algorithm

The system recommends items based on similarity between user preferences and item categories.

Steps:
1. User selects one or more preferred categories
2. System matches items with those categories
3. Matching items are collected
4. Items are sorted based on rating (highest first)
5. Top results are displayed to the user
